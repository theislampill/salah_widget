## How to read this projection

Each manifest row records the original local SHA-256, the projected-byte
SHA-256, and the stored-byte SHA-256. Named Windows roots are replaced only in
text copies. Numerical observations and embedded hashes are preserved.
Projected scripts are provenance copies; their aliased paths are not runnable
host paths. Larger JSON/JSONL files are losslessly compressed with gzip and
have a `.gz` suffix. Decompression yields the `projectionSha256` bytes.

PNG/JPEG/WebM bytes are unchanged. The WebM files were originally resampled to
25 fps; selected original source JPEGs named in reviews and the solar analysis
are included.
The full original-frame archive remains in local custody. A WebM recording,
late still, screenshot crop or diagnostic metric cannot repair an unreadable
original continuous watch. Empty, failed and interrupted acquisitions retain
their distinct status. A runner's successful exit is not a visual PASS.

This bounded packet excludes browser profiles/storage, credentials, clipboard
or personal desktop data, installed runtimes, font binaries, repository tar
archives and the private owner instruction attachment. Some source references
point to separately committed public source; some review references name
retained local evidence outside this projection. Manifest membership, not a
path mention, determines what is published here. No absent artifact is implied
to have been published.
