# R003F matrix source reconstruction

## Goal

Reconstruct the lost, unpublished matrix and motion harness extension from the
published R003F recipes. Give this reconstruction its own source identity and
fresh offline verification. The old unpublished head and historical review are
context, not qualifications of these bytes.

## Architecture and scope

An exact-SHA materializer reads fourteen published files and writes sixteen
files into a fresh disposable directory. It preserves the original product
bytes, matrix population, physical checks, source-variant transforms, motion
clock and native intake. Added observation code corrects CSS MIME, retains
native UI facts and partial captures, records late lifecycle faults, and
requires an externally supplied materialization digest at execution and replay.
The hosted planner, registry and acquisition integration are a later reviewed
packet. This packet cannot launch or qualify a hosted campaign by itself.

Tech stack: Node CommonJS, the existing Playwright recipes and pngjs 7, FFV1
through local ffmpeg/ffprobe for synthetic controls only.

checked against the published research SHA-256 before any output is created.
