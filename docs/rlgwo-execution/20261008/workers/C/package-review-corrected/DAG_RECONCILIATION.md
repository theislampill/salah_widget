The new graph uses three distinct relationships: hard input/interface dependencies, qualification/review/integration gates, and capacity-limited resources. Sharing a file, native platform or browser machine is a scheduling conflict, not by itself a semantic dependency. Administrative issue closure is never a substitute for a proved input contract and is never made a prerequisite merely for tidy numbering.

No production or scientific status changes are made by this documentation package. A future executor must recheck main, contracts, startup handoff and current evidence before beginning nodes. Source changes invalidate only the evidence whose relevant owner/interface/input/platform can change, with an explicit reuse argument for retained receipts.
