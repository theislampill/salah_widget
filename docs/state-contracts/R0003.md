## Defect (base)

`applyConfig` (L3678-3709) has exactly one narrow branch, `appearanceOnly` (L3684-3698), which requires the
appearance to *differ*. Every other apply — a label, 12/24-hour or date-format edit, and an apply whose values
are all equal (settings close after a reverted edit, a retry of a failed save) — runs the broad chain:
`beginRuntimeGeneration` (L1050: generation++, every request slot cleared, attempts aborted), `bindConfig`
(L683: live provider-adopted `tz` replaced by the configured hint, `_cacheTz` re-frozen), `resetForNewLocation`
(L3666: prayer records and weather/radar records dropped, `lastWxTry/lastRadarAt` zeroed, R000D `_wxRetry`
records cleared, timetable withdrawn to "—", `beginSkyScene` restarting the sky), `startWeather` and
`loadPrayerData` (new provider requests). A legitimate in-flight request for the current target is cancelled.

## Owner decisions (2026-11-11, binding defaults)

- **D1** explicit user Reset is a real reset even when values equal the current configuration (explicit internal
  reset intent so equality cannot swallow it). An ordinary retry of a failed save with unchanged semantic
  configuration must not restart prayer, weather, radar or sky, but executes and truthfully reports the
  persistence attempt. Reset ownership and R0011 storage-warning behaviour preserved.
- **D2** same coordinates with different provenance / acquisition time / accuracy / provider / location intent or
  other semantically relevant evidence is **not** cosmetic → conservative broad path.
- **D3** `lp` and `seed` stay on the conservative path; actual consumers documented; no optimization claim.
- **D4** `units` weather-only optimization deferred; conservative path.
- **D5** no reorder: R000D → R0026 → R0003; R0003 consumes the merged R0026 admission/evidence contract.
- **D6** bounded affected-case native set, Chromium and Firefox.
- **D7** small pure classifier in `src/native/index.html` with a complete, production-consumed field/effect table;
  `applyConfig` stays the sole effect dispatcher; no public configuration API, persisted generation or event
  framework.
- **D8** immediate update of the directly owned label; `_renderDirty` for presentation; no forced background
  rendering when hidden/offscreen; a paused widget shows the pending change on its first legitimate resumed render.
- **D9** new source tests are executed by the documented route with exact results retained; no CI ceremony.
- **D10** card geometry and design preserved; verify which formatting changes need fit recalculation; CSS ellipsis
  behaviour documented and tested; native checks for long date formats and 12-hour time.

No criterion contradicts a decision. ES03-12 ("Save denial/reset/close-reopen feedback preserve R0011/R000F") is
read together with D1: Reset keeps its broad effect, persistence feedback is published before any dispatch.

## Field/effect table

The production table is `CONFIG_EFFECTS` (classifier block between `bindConfig` and `if(window.SalahConfig)`),
consumed once by `applyConfig`. Every key any real producer can put on a WidgetConfig has a row (producers:
`SalahConfig.normalize`, `resolve` (hash), `loadLocal` (`origin`), `coarseDetect` (`detectProvider`, `area`,
`accuracy`), `applyHashPrefs`, `_settingsFormToConfig`). A key with no row, in either the accepted or the proposed
configuration, fails closed to the broad path; a test fails if a producer emits a key without a row or a row has
no producer.

Consequence columns: **Gen** generation bump (aborts in-flight prayer/weather/radar attempts, clears slots);
**Key** cache-key change possible; **TZ** live `tz` reset to the hint and `_cacheTz` re-frozen; **Thr** weather/radar
throttles and R000D `_wxRetry` records cleared; **Sky** `beginSkyScene` restart + timetable withdrawal; **Acq** new
prayer/weather/radar acquisition; **Fit** JS fit recalculation; **Dirty** `_renderDirty`.

| Field | Effect class | Actual runtime consumers | Path | Gen | Key | TZ | Thr | Sky | Acq | Fit | Dirty |
|---|---|---|---|---|---|---|---|---|---|---|---|
| `label` | label | `label` → `setLocLabel` (`#loc` text + display); settings echo | presentation | no | no | no | no | no | no | none (CSS) | yes, plus immediate `setLocLabel()` |

## Limits

- Native visibility is driven through the widget's own `visibilitychange` handler with a forced
  `document.visibilityState`; no real tab switch or offscreen scroll. Headless only.
- Weather/radar ownership under a cosmetic edit is proven at source level with real owned slots and R000D records
  (the r0003 harness doubles `fetchWeather/fetchRadar`); natively it is shown as zero new weather/radar requests and
  an unchanged generation, not as a held weather response.
- No network, latency, flicker or battery measurement or claim.
- `seed` has no in-place runtime consumer that was found; it stays broad (D3) and no saving is claimed. Units,
  method/school, lp, evidence/provenance and tz keep the conservative broad path.
