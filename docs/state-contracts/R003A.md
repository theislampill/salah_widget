**Fault path (re-derived; the registry's "≤ 1 frame after a scene reset" was wrong).** Without a published timetable,
`render()` runs stage `weather-withdrawal` (`reconcileCloudPublication`; `withdrawWeatherEffects`) with one bounded retry

- a throw in any painter body call (`renderMoon`, `projectStars`, `lunarPresentation`, `wxDrivers`,
