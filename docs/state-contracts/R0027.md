## Specification facts used (issue #69 is the authority)

- Inner fit cache `sfFitCache`: bounded deterministic Map, **at most 12,000 exact fits**, **FIFO**: evict the
  oldest retained key before inserting a new key at capacity. Hits reuse the existing fit. The capacity is the
  outer map's scale borrowed as a declared engineering bound, not a measured optimum.
- Outer selection cache `sfCache`: **unchanged** (admission stops at 12,000; never evicts). Bounding only the
  outer map is a rejected alternative; the outer map is not bounded further.
- No quantised keys, no change to tables, fit iterations, Planck arithmetic, domain/fallback/provenance logic.
- Route: one authored digest-guarded transform `tools/native_core_spectral_cache.py` invoked by
  `tools/build_native.py`; vendor bytes immutable; generated copies never hand-edited.
- The dossier's proposal (capacity, policy, inner-only bound, two spans, `sf`-prefixed constant) agrees with the
  spec; no design difference was found.

- What is fitted: `sfFitColour(bv)` (`:21-24`, private, sole caller `selectSpectrum` `:38`) solves a Planck
  temperature by 48 log-temperature bisection steps on `syntheticBV(blackbodyShape(mid))` (`:22`),
  `T=Math.sqrt(lo*hi)`, and stores the 95-sample V-normalised spectrum and `T`. Reached only with no `sed`,
  no HIP standard, no matched template, `-.4<=bv<=2` (`:38`) and inside the fit domain (`:21`: returns `null`,
  nothing stored, for B−V below that of 200,000 K, −0.27361…, or above that of 1,500 K).
- Growth path: every distinct admissible exact B−V adds one entry forever. Producers:
  `createSkyModel` (`real-sky/core/src/sky-background.mjs:72-76`) via `patatTwilight(sun alt).bv`
  (`:29-33`, continuous for sun altitude in (−15°, −3°)); the first-paint preview
  `nativeAtmosphereFields` (`real-sky/native-preview.mjs:333-338`, B−V of the Patat fit at the clamped
  reference altitude, continuous for (−15°, −5°)); catalogue stars via `spectralStarFlux` (`spectral.mjs:48-49`),
  a finite population.
- Immutability (owner decision 3): `selectSpectrum` freezes the returned value and its `samples` (`:41`); for a
  fitted colour that array is the same array as `fit.samples` (spread at `:38`). Externally returned sample
  arrays are therefore frozen and remain valid after eviction (eviction is only `Map.delete`). The internal fit
  record is not frozen and does not escape the module. No `Object.freeze(fit)` is added.
- Instances (owner decisions 6–7): the generator concatenates the core into one scope per bundle
  (`tools/build_native.py:21-46`), so one document can hold three independent instances, each with its own
  pair of maps: the inline first-paint script in `index.html`, the `real-sky/native-sky.js` UI realm, and the
  worker (`real-sky/native-worker.js`, embedded in `native-sky.js`). `offline.html` inlines the same three.
  The bound is per instance; nothing is shared across instances; worker/document retirement ends a realm;
  an asset retry in the same realm does not clear its maps; no periodic clearing.

## Authorised route, forbidden actions, protected invariants

- Authored: `tools/native_core_spectral_cache.py` (new) and one `elif` + import in `tools/build_native.py`.
  Regenerated only by `python tools/build_native.py`: `real-sky/core/src/spectral.mjs`,
  `real-sky/native-worker.js`, `real-sky/native-sky.js`, `index.html`, `offline.html`.
- Forbidden: editing `vendor/**`, `real-sky/core/**` or any generated bundle by hand; touching `moon/`,
  `src/native/index.html`, `config.js`, `builder.html`, `v1/`; rounding/quantising B−V; changing tables,
  iterations, Planck arithmetic, fallbacks or precision; bounding only the outer map; per-frame/periodic
  clearing; global sharing of rendering state; widening the horizon exception.
- Protected: the horizon transform (`tools/native_core_horizon.py`) and its drift test; V1
  (`python tools/verify_v1.py`); all AGENTS.md visual gates (unaffected by construction: the numbers are
  bit-identical, and that identity is proved directly rather than by pixel opinion).
