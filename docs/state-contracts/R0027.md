## Specification facts used (issue #69 is the authority)

- Inner fit cache `sfFitCache`: bounded deterministic Map, **at most 12,000 exact fits**, **FIFO**: evict the
  oldest retained key before inserting a new key at capacity. Hits reuse the existing fit. The capacity is the
  outer map's scale borrowed as a declared engineering bound, not a measured optimum.
- Outer selection cache `sfCache`: **unchanged** (admission stops at 12,000; never evicts). Bounding only the
  outer map is a rejected alternative; the outer map is not bounded further.
- No quantised keys, no change to tables, fit iterations, Planck arithmetic, domain/fallback/provenance logic.
- Route: one authored digest-guarded transform `tools/native_core_spectral_cache.py` invoked by
  `tools/build_native.py`; vendor bytes immutable; generated copies never hand-edited.
- The dossier's proposal (capacity, policy, inner-only bound, two spans, `sf`-prefixed constant) agrees with the
  spec; no design difference was found.

- Immutability (owner decision 3): `selectSpectrum` freezes the returned value and its `samples` (`:41`); for a
  fitted colour that array is the same array as `fit.samples` (spread at `:38`). Externally returned sample

  The bound is per instance; nothing is shared across instances; worker/document retirement ends a realm;
  an asset retry in the same realm does not clear its maps; no periodic clearing.

## Implemented delta (candidate)

Authored: `tools/native_core_spectral_cache.py` (new) and in `tools/build_native.py` one import plus
`elif p=='src/spectral.mjs':target.write_bytes(bound_spectral_cache((S/p).read_bytes()))` in the core-copy loop.
The transform pins the input digest and the output digest, requires each anchor exactly once and refuses an
already-transformed text. The generated `real-sky/core/src/spectral.mjs` differs from vendor by exactly:

- Span A (`:9`): `sfCache=new Map(),sfFitCache=new Map();` →
  `sfCache=new Map(),sfFitCache=new Map(),sfFitCacheLimit=12000;` plus two comment lines.
- Span B (`:23`, now `:25`): before `sfFitCache.set(bv,fit);return fit;` insert
  `if(sfFitCache.size>=sfFitCacheLimit)sfFitCache.delete(sfFitCache.keys().next().value);`.

The eviction runs only after a successful fit (a `null` out-of-domain result or a thrown `RangeError` never
reaches it); `bv` is absent at that point (`has` early return), so the map never exceeds 12,000; a hit never
writes. `AGENTS.md` names this narrow exception (the spec's "explicit matching source-ownership instruction").
