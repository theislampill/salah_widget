## Product behavior under qualification

For an already acquired local script, `DRY_RUN=1 bash ./install.sh` and `powershell -File .\install.ps1 -DryRun` perform local discovery and report what remains unresolved. Acquiring the script is a separate network operation. Preview does not ask installation questions, contact release/provider endpoints, create temporary or retained directories, adopt cached files as ready artifacts, extract an archive, rewrite a preset, mutate a clipboard, open a browser or run cleanup. Suppressed helpers return no usable path; suppressed clipboard calls return failure/Boolean false.

Unknown metadata remains held, and legacy targets remain refused. Independently eligible peers can still receive useful plans. When no selected target is eligible, preview exits unsuccessfully without claiming staged or installed success. Missing assets, malformed existing cache/preset bytes and early option failures do not justify preview effects. Remote release, version and path facts and unresolved source choices remain unresolved.

Normal mode still downloads, validates, stages retained files and hands them to manual browser consumers. `NO_OPEN=1` / `-NoOpen` suppresses browser opening while retaining normal downloads, configuration, clipboard handoff and manual confirmation behavior. A staged or handed-off bundle is not a completed browser installation or import. Existing card, permission, configuration and manual dashboard-replacement obligations remain in scope.
