## 1. Machine RV — builder reverse lookup (`src/native/builder.html`)

Owner: the builder script. Functions: `admitReverse`, `fillNameFromCoords`, `setMode` (mode epoch only), and the
unchanged lat/lon input listener (700 ms debounce) and `locate` continuation.

| Dimension | Values |
|---|---|
| request | not-scheduled, debouncing, pending, settled |
| outcome | admitted, http, parse, admission, timeout, transport, superseded |
| per-field admission | label, countryCode, continentCode — each admitted / absent-or-invalid |
| mode | portable, local; `reverseModeEpoch` counts actual mode changes |
| auto flags | `labelAuto`, `methodAuto` (unchanged) |

| From | Event | Guard | To / effect |
|---|---|---|---|
| idle | lat/lon input | (existing) | debouncing, 700 ms |
| debouncing | timer | current `locationEdit`; **portable mode**; an auto flag on; numeric draft | pending: one `fetch` with `{referrerPolicy:"no-referrer", signal}` and one 8 s deadline (`REVERSE_DEADLINE_MS`) |
| debouncing | timer | local mode | settled, **no request** (D-31-1 A) |
| pending | headers | `r.ok !== true` | settled(http): no writes |
| pending | headers OK | — | body parse inside the same deadline |
| pending | deadline | — | settled(timeout): `abort()`; a later body or rejection is inert and handled |
| pending | fetch/parse rejects | — | settled(transport/parse): no writes |
| parsed | — | `ownsLookup(owner)` false | superseded (R000F, unchanged gate) |
| parsed | — | body not a plain object, or mode epoch changed, or now local | settled(parse/superseded): no writes |
| admitted | — | per field | `homeCC` ← two-letter alphabetic `countryCode` (lower-cased); label ← first non-empty trimmed string ≤ 200 chars of `city`/`locality`/`principalSubdivision`/`countryName` if `labelAuto`; method ← `continentCode` matching `/^[A-Z]{2}$/`, `"NA"` → `"2"`, any other admitted code → `"4"`, if `methodAuto`; then `update()` |

Invariants. (I1) No method change without an admitted `continentCode`; absent, empty or malformed is absence of
evidence. (I2) No request outlives its deadline in effect; the deadline timer is cleared on settlement. (I3) A
superseded lookup (newer edit, newer lookup, or mode change) has no effect. (I4) No new recipient; the body is not
persisted. (I5) The region → method policy is unchanged (D-31-2).

Failure/recovery. Failures stay silent in the tip area (default; no new text). The next eligible coordinate edit is
the retry; switching local → portable schedules no catch-up lookup.

Shape rule. No BigDataCloud reference is cited; the repository evidences `NA`, `EU`, `AS` only. The seven usual
continent codes are an assumption used to choose positive test values. Any well-formed two-upper-case-letter code
other than `NA` (for example `ZZ`) maps to `"4"`, exactly as every non-`NA` value did before.
