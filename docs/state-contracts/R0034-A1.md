## Defect

`real-sky/native-host.mjs` `accept()` (main L219) chose the lattice for the host-side display decomposition as
`altDeg < -3 ? [⌈325/step⌉, ⌈530/step⌉] : [24,40]`. The worker samples the background on
`[⌈325/step⌉, ⌈530/step⌉]` (step 8 → 41×67, `real-sky/core/src/physical-sky-renderer.mjs` L47). In daylight
`nativeSkyPresentation` (`real-sky/native-preview.mjs` L132+) computes `shown = source + aureole·(gain − 1)` with
`source` on 41×67 and `aureole` (solar aerosol share) on 24×40. Near the physical Sun `gain ≈ 0` above 20° solar
altitude, so the display carries `interp₄₁ₓ₆₇(f) − interp₂₄ₓ₄₀(f_aer)`: soft vertical and horizontal ridges around
the physical Sun's camera position (the owner-reported bars under issue 101). The comment above the line requires
the worker's nodes for twilight's solar-only shoulder and the lunar/natural share; applying it to the daytime aureole
is the investigator's and verifier's reading — the defect rests on the arithmetic above, not on the comment. The line was introduced in `dbc0387b`
(2026-10-07) with no recorded rationale.

## Change

One authored expression in `real-sky/native-host.mjs`: `grid=[Math.ceil(325/step),Math.ceil(530/step)]` at every
solar altitude handled by the host decomposition (−20° and above; deep night keeps the worker-prepared lunar
display and runs no host decomposition), plus a four-line comment. Generated `real-sky/native-sky.js`,
`offline.html`, `GENERATED.json` regenerated by `python tools/build_native.py` (twice; second run clean).
No core, vendor, encoder, CSS, worker or preview change.

## Producer contract after the change

- Inputs: accepted worker raster (`skyBackgroundLinear` on the worker lattice), `physicalState`, `atmosphere`,
  `view`, the measured corner anchor.
- Invariant: **the removed aureole and the field it is removed from are sampled on the same lattice at every solar
  altitude** (worker lattice `[⌈325/step⌉, ⌈530/step⌉]`).
- Composition order unchanged: worker raster → host fields (`nativeAtmosphereFields`) → `nativeSkyPresentation` →
  `compose()` (clouds/Moon/calendar) → `encodeNativeDisplay`.
- Failure behaviour unchanged (same throw sites, same withdrawal path).
- Preview unchanged (its own background and aureole share [24,40], or [12,20] when fast; they cancel).
- Performance: Node, fields + presentation, owner scene: +19.6 ms median (130.3 → 149.9 ms, 15 runs; the
  independent candidate review measured ≈ +17 ms); in browsers the change is within run-to-run noise (verifier:
  `nativeAtmosphereFields` 40 → 41 ms Chromium, 27 → 28 ms Firefox). Nodes 1025 → 2856. Worker message unchanged.
