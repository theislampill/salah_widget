## 4. Tests added

### 4.1 ISM-MOON-007 — `moon/tests/worker-pump.test.cjs` (9 cases)

Evaluates the raw `moon/src/moon-worker.mjs` in a vm realm (globals `MoonPool`, `adaptiveRender`,
`nativeCalendarResult`, the asset manifest as stubs; `self` records posts; each job's `adaptiveRender` is held on a
gate the test settles). States covered: idle, running(serial), running plus latest queued, cancelled, failed.
Invariants asserted: at most one top-level pipeline; a preview, result or error publishes only while its serial is
current; a job sent during execution is served after the running one settles and is consumed once; `cancel` drops
the queued job and silences the running one; a current error is reported and does not wedge the pump; jobs sent
before the engine exists collapse to the newest.

Mutants (in memory, from the shipped text, each must fail): (a) publication serial check removed, (b) error serial
check removed, (c) running guard removed, (d) latest not consumed, (e) queued job kept on `cancel`, (f) `while`
loop and `finally` re-pump removed together. All six are killed. **Equivalent mutants recorded, as the issue
requires:** removing only the `finally` re-pump survives, and removing only the `while` loop (keeping the re-pump)
also survives, because the two are mutually redundant (between loop exit and `finally` the code is synchronous and
the boot-error `catch` sets `latest=null`); only their joint removal is observable.

### 4.2 ISM-MOON-010 — `moon/tests/engine-exclusivity.test.cjs` (3 cases)

A second `render` started while one is active rejects with `One owned Moon computation at a time`; the first
completes with an unchanged result (byte comparison against a baseline); a render after settlement and after a
cancellation (`AbortError`) succeeds, and `active` is false after each. Mutants: guard removed; the release in
`finally` removed: both fail the same discriminator.

### 4.3 ISM-SKY-021 — `tests/real-sky/native-display-geometry-cache.test.mjs` (5 cases)

Loads the real `real-sky/native-preview.mjs` (imports rewritten to absolute URLs, an inspection export appended) and
drives it through `nativeSolarRegistration`: six distinct camera views leave exactly four entries with the oldest
evicted and growth 1, 2, 3, 4, 4, 4; a repeated view returns the same memoised object for every retained entry
(eviction is FIFO, a hit does not refresh); precondition case shows the Sun path reaches the memo. Mutants:
eviction statement removed; cache hit removed: both fail.

RED is not expected for any of the three (they verify existing behaviour); discrimination is shown by the mutants.
The pre-existing behaviour on main is unchanged (`git diff` of product files is empty).

## 6. Findings (recorded, not fixed, no test added: the bound is three)

- **F-1 (ISM-SKY-010).** Rejection of in-flight renders by `ReferenceRenderClient.dispose()` is unasserted (W4
  survives; the vendor case submits only after disposal). A probe shows the code rejects with `Render client
  disposed` and terminates the worker today. Consequence is bounded: the queue is disposed first and publishes
  nothing. Candidate narrow test: a vendor-level case in a future work order that owns vendor tests (this one may not
  edit `vendor/real-sky`); a repository-level case could drive the client through its public API.
- **F-2 (ISM-SKY-013).** A late failure of a superseded `replaceAsync` clearing the current catalogue is unasserted
  (C2). `replaceAsync` has no shipped caller (only `SkyController.update` is reached through `PhysicalSkyBridge`),
  so the transition is dormant. Trigger: a shipped caller.
- **F-3 (ISM-SKY-029).** The forged-descriptor case offers only `{catalogueSha256}`; forgery by a `kind` field is
  unasserted (B2). The issue cited `cp74_transport` as evidence for "exact bytes": that file uses the binding as a
  fixture for transport physics and does not exercise the capability, so the row is not credited with it.
- **F-4 (ISM-MOON-006).** The stale-script protection is layered: the callback is deleted and the handlers nulled at
  release, and two guards check worker and disposal. The observable behaviour is asserted; no test isolates the
  guards (H1, H4, H5, H6 survive). The per-script identity clauses are unasserted.
- **F-5 (ISM-MOON-009).** The `physicalIdentity` equality clause of the join guard has a surviving single-clause
  mutant (P3); the clause overlaps others and the cause was not isolated.
- **F-6 (equivalent mutants).** MOON-007 `finally` re-pump and `while` loop (section 4.1); SKY-012 A1 and A5 (no
  await between the two checks); SKY-013 C3. Each is reported with its reason and none is "fixed".
- **F-7 (R28-L13).** `tests/expected-failures.json` declares the `cp74_compositor` red case under owner R0038 with
  the discriminator "run on a Linux host and at the vendor-recorded Node version". **Not run:** this executor has only
  Windows with Node 24.14.0, and no vendor edit is allowed. Cause class stays `undetermined`; section 7.
- **F-8 (ISM-SKY-025).** `spectrumForColour` and `starRgbFlux` are dead code in the shipped bundles.
- **F-9 (ISM-MOON-011).** Exercised indirectly only. A probe (not committed) counted the `MessageChannel` wake-ups
  in real renders: 3, 27 and 95 for 32, 128 and 256 px scenes; a cancellation raised at a yield boundary produced
  `AbortError`.
- **F-10 (issue citations corrected).** ISM-SKY-007 (construction custody is not the queue protocol), ISM-SKY-021
  (`cp9-presentation-cache` asserts no bound), ISM-SKY-029 (`cp74_transport`), ISM-MOON-007 (`moon-worker-fixture`
  covers the wrapper) cited tests that do not exercise the named transition.
