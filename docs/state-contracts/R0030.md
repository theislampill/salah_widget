## 3. Commit-failure contract (PRA-F-33, G3-a)

`_commitSettings` and the deferred Reset commits go through `_applySettings(cfg,save)`, which attaches
`.then(success, failure)`; `_resetLocal` awaits its apply inside `try/catch`. A rejection is logged once
(`console.error`) and sets `_setApplyFault` (sanitised error name); `_outcomeMessage()` then appends
"Settings could not be applied (<name>). Reload the widget to try again." to the existing persistence line in the
live region and the panel status (`err` class). The published persistence fact is kept (no rollback, no retry, no
second loop). Each settings apply (close-save, deferred Reset commit, Reset apply) takes an issue number
`_setApplySeq`; only the latest-issued apply writes or withdraws the line, so a stale success cannot withdraw a
newer failure and a stale failure cannot overwrite a newer outcome (review F3; every rejection is still logged).
In every non-failure path `_setApplyFault` is null and the text is byte-identical to main.

Fault-only limit (tested, `F2 limit` case, mutant `commit-after-reset-fault`): if the Reset apply itself rejects
while the panel is closed, the Reset owner is dropped and edits recorded by a close are **not** applied or saved;
committing them would re-persist whatever site the failed apply left (the pre-Reset site when `bindConfig`
threw first), breaching I1. The G3 line reports the failure. With the dispatching panel open the form is
repopulated from that runtime state, so I1 can be breached under the same injected fault.

## 9. Limits

- Fault-only: a Reset apply that rejects drops the owner (§3); with the dispatching panel open the form is
  repopulated from whatever runtime state the failed apply left.
- A pending search or GPS request is abandoned if the Reset target lands first in the dispatching session (the
  repopulation invalidates lookups, as on main); the issue makes the candidate/fix, not the request, the intent.
- VM evidence uses the r0011 fixture's provider and renderer doubles; the window length is not measured; native
  cells use route stubs and a held detection, not real providers or real geolocation.
