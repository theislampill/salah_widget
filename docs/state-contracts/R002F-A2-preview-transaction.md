# R002F-A2 preview replacement experiment

A current preview can replace its background, device-resolution lunar join and decoded solar mask together under the source-controlled fault schedules below. One attribute on the existing card selects a prepared generation, including the receipt reported to a reader during that write. The shipped owners have not changed. Ordinary initial paint, preview-to-refined handoff, native frame timing and atmospheric presentation after loss of authority are outside this result.

## Failure reproduced on the actual owners

An accepted fixture at UTC 0 has a background digest beginning `f0332b57` and a lunar canvas digest beginning `f4366ffc`. An ordinary successful replacement at UTC 21,000 produces `d8fee762` and `607a4334`. Rejecting the old preview owner's next background upload after the real lunar join leaves `f0332b57` and `607a4334` visible in the fixture; the Sun mask and receipt still identify the original frame. This is the same failure exposed by the separate single-upload study. It takes no position on how often a browser suffers that fault.

## Disposable mechanism

The materializer checks six source hashes. It transforms five authored owners: the preview, foreground capture, native sky hook, lunar presenter and native application. The device-detail source and its initial-receiver association remain byte-identical. The experiment derives a second private render target from that exact detail implementation, removing DOM attachment, using a read-only adoption predicate in place of the publishing surface accessor, and exposing geometry for a final comparison. Its area sampler, gas/stellar/cloud joins and encoding execute the existing arithmetic. It deliberately repeats material preparation in this experiment.

- The lunar presenter records the material views in a weak map keyed by the actual accepted object. A lease requires that object, epoch, clock, original phase bound, presenter identity, device footprint and altitude blend to remain current. A queued replacement disqualifies it. Reading a lease cannot adopt the queued surface or publish a texture. The original foreground route is retained outside eligible preview replacement.
- The preview constructs a private full background, completes the lunar join on a detached canvas and prepares a style for the decoded mask. Each attempt gets its own nodes and an ID unique on the card. The original solar-anchor geometry is available through a presentation-only read that omits the publishing lunar surface accessor. Insertion keeps those nodes hidden. CSS applies the mask at the Sun's own element; the original sky and lunar nodes stay at their established stack positions.
- After rechecking the original job, cloud receipt, Moon, catalogue, mask revision and replacement ownership, one card attribute selects the successor. Reads during that write resolve its prebuilt receipt. If the selector writes and then throws, the host reads back the selected generation. A losing attempt can dispose only its own nodes. Newer generations and refined ownership take precedence. Every ordinary presentation checks an already selected generation before the 100 ms refresh throttle. A new lunar adoption or cloud receipt, and completion of native lunar geometry, check in the same producer task. Failed authority first retracts the selected receipt, original ready class, mask and canvas visibility. A single scoped CSS rule keeps any obsolete underlying canvas hidden if owner cleanup throws. A new valid owner can publish during cleanup without being retired by its predecessor. The existing successor routes are used when replacement evidence is available. There is no additional grace period.
- Successive regional updates use the immutable atmospheric base and the current foreground footprint. The research implementation copies a full 325 × 530 background for every staged presentation and builds another device-resolution detail. This is a deliberate source experiment; observer-visible cost, peak retention and native cadence are unmeasured.

The selector fixture evaluates the emitted subset of CSS declarations over individual connected nodes and their recorded RGBA bytes. It uses the actual lunar projection/transfer/encoding functions and the actual preview and solar publication owners. The atmospheric input, DOM layout, contexts, CSS evaluator and transport are doubles. There is no native layout/compositor, GPU-lifetime or device-cost claim. Context loss, a failed paint after successful JS selection and arbitrary DOM corruption require different evidence. An independently current old preview is the only retention case studied. No original unpublished A2 candidate or accepted product policy is inferred.

## Reproduction

Run from this tree. The materializer requires a new output directory and emits the exact five authored postimages, patch and manifest. Apply the patch only in a disposable checkout.

```sh
node --test tests/r002f-a2-preview-transaction.test.cjs
node tools/qa/r002f-transaction/experiment.cjs > /tmp/transaction-source-results.json
node tools/qa/r002f-transaction/materialize.cjs /tmp/fresh-transaction-patch
git -C /path/to/disposable/tree apply /tmp/fresh-transaction-patch/transaction.patch
python /path/to/disposable/tree/tools/build_native.py
python /path/to/disposable/tree/tools/build_native.py
```

A product assertion did not run in that invocation.
