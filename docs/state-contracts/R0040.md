## Provider and physical parameters

- Open-Meteo defines current precipitation as an accumulation over the preceding `current.interval` seconds. Its hourly table defines total precipitation as the combined water amount from rain, showers and snow. Large-scale rain and convective showers are components of that total. Its 15-minute table lists all three amounts as backward-looking sums, with regional model coverage and interpolation. An hourly equivalent is `amount_mm × 3600 / interval_s`. It describes a modelled interval average and grants no instantaneous rate or local observation. [Open-Meteo Forecast API, 15-Minutely Parameter Definition and JSON Return Object](https://open-meteo.com/en/docs)
- The coefficients used by the research prototype match the drizzle and thunderstorm distributions in Chwala et al., Table 1. For their exponential model, drizzle uses an intercept of 30,000 m⁻³ mm⁻¹ and slope 5.70 R⁻⁰·²¹ mm⁻¹. The thunderstorm case uses 1,400 and 3.00 R⁻⁰·²¹ in the same units. The authors treat these as extremes. Applying the thunderstorm distribution to every model shower code still lacks support. [Chwala et al., Atmospheric Research 144 (2014), Table 1](https://opus.bibliothek.uni-augsburg.de/opus4/files/38762/0407.pdf)
- At 0.30, 0.40 and 0.50 mm diameter, Stout et al., Table 2, report the Gunn–Kinzer still-air values of 1.17, 1.62 and 2.06 m/s used in the prototype's table. The implementation switches to its Atlas fit at 0.50 mm. This cross-check covers those three entries only. [Stout et al., Journal of the Atmospheric Sciences 50 (1993), Table 2](https://www.ars.usda.gov/ARSUserFiles/30960515/Stout_pubs/Stout_1993_JAS_Sinusoidal.pdf)
- The 125 m/K temperature–dew-point rule estimates the lifting condensation level of an adiabatically lifted parcel. Romps compares that approximation to an exact LCL calculation. Its use for the actual base of a rain-bearing stratiform deck, including the prototype's 100–2,000 m clamp, remains unverified. [Romps, Journal of the Atmospheric Sciences 74 (2017), Eq. 1](https://romps.berkeley.edu/papers/16lcl.pdf)
