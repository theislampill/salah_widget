# R000D retrospective

Issue #13 was intentionally closed as completed only after the accepted
CLOSE-R000D comment was posted and independently read back with every cited
reference while the issue remained open. The final readback binds the exact
events; this retrospective does not replace that evidence.

- Reuse: the existing generation, operation and attempt ownership and deadline
  implementation required no product repair. R0003 supplied compatible loader,
  fixture and public-consumer components, with explicit source and interface
  bindings. R000D separately qualified its three semantic mutants, ten native
  timeout/recovery cases, late-owner controls and affected night presentation.
- Abnormalities: one obsolete font-link expectation and one Firefox teardown
  exception invalidated their original attempts. Historical blank recordings
  and current Chromium crop/gray intervals stayed unqualified. Publication also
  exposed CRLF checking and read-only command/endpoint mistakes; none became a
  product failure or a false test pass.
- Countermeasures: correct the bounded expectation; checkpoint custody before
  teardown and preserve close errors separately; independently qualify distinct
  successor attempts. Credit only inspected original 30-second Chromium
  intervals and the authorized Firefox PNG/render/canvas route. Preserve raw
  bytes with command-local CRLF recognition and use structured argument lists.
- R0018 reuse: the committed evidence retains `run_native.py`, the adapted
  `package/tools/qa/run_r000d_transport.py`, execution manifests, fixture hashes,
  normal-poll observations, native provider controls, `run_public_readback_v2.py`
  and byte-delivery checks. Reuse those mechanisms only after checking the next
  issue's source, input, observer and environment compatibility; no R000D PASS
  transfers automatically. Keep browser runs serial, original failures intact,
  and evidence on a separate non-deploying branch.

The production change remained sixteen documentation additions in README.md and
DESIGN.md. All 135 runtime files, authored implementation, configuration, tests,
generated consumers and frozen V1 stayed unchanged. Four inherited TODOs remain
TODO; model estimates are not physical observations, radar alpha is unitless,
and the disclosed radar wall-clock offset is not a real ten-minute watch.
