**Goal:** Split existing worker preparation costs into bounded aggregate

rendering calculations and original failures.

## Design and constraints

The existing `prepareStars` runs before the later replay scope filter. Each
eligible star calls `spectralStarFlux` with its existing 95-sample transport
callback, then `preparePatch` calls the reference renderer. That renderer has
three wavelength channels and two positive Gaussian components per drawn patch.
`prepareReplay` performs calendar transfer, nominal composition, envelope
accumulation, two full-frame extremum compositions, variable-pixel selection,
patch weights, input gathers, and center withdrawal composition/ranking.

Changing scopes, adding caches, or replacing spectral/PSF calculations would
change the work being measured. Direct production-module edits would also mix
diagnostics with the candidate. The selected approach therefore instruments
only the disposable lab through exact, reversible source substitutions, with
all unchanged dependency bytes inventoried. A small added collector module is
explicitly part of the derivative closure.

- Record one fixed-size cost object per existing worker preparation trace.
- Count operations only where the original code already executes them, or derive
  counts from an already-returned size/drawn count with that derivation declared.
- Add no per-star history, pixel scan, I/O, repeated producer polling or cache.
- Keep partial failed operations distinguishable from completed operations.
- Subtract only one worker's timestamps. Added marks have uncalibrated overhead.
- Keep the original native reports and default guard/cadence/publication failures.
- Preserve original driver arguments, route/namespace, cleanup and outer failure
  precedence. No generic product PASS follows from diagnostic completeness.
- Keep the existing restart condition unchanged; no extra comparisons or scans.
- First selection is explicit Chromium stage timing, guard off, full population,
  ordinary clock, dark scene, normal motion, three original arms, one round.
- No browser/native execution or remote writes by this author.

## Review focus

1. Original and instrumented stellar flux, patch bytes, populations and errors
   must match, including empty/ineligible/zero-flux and clipped patches.
2. Nominal bytes, full replay outputs, source/center counts and sampled outputs
   must match with preview/full, glass, masks, clouds and lunar foregrounds.
3. Incomplete worker preparation must retain an honest bounded prefix; empty,
   unknown, duplicated, impossible or cross-domain cost claims cannot be admitted.
4. Derived source/plan identity must bind every original and added file. Changing
   a scalar pin or dropping a file cannot create an admitted original identity.
5. Optional preparation failure, invalid intake, original failure, veto, late
   cleanup and timeout retain their existing authority and raw evidence.
