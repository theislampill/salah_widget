lab. It does not change the candidate, choose a production policy, relax a guard,
add a cache or make an acceptance claim. Original candidate failures and
owner-reserved decisions remain in force.

must not be interpreted as hardware instruction counts. Derived counters do not
add a second scan. Source and replay population counters are checked against the
already-recorded worker stage marks at final intake.

## Timing and incomplete work

All bucket durations use one worker's `performance.now()` clock. They include
uncalibrated clock reads and counter overhead; there is no claim about observer
cost, production cadence, cache benefit or cross-machine performance. Page and
worker clocks are never subtracted from each other. No cross-domain residual is
called transfer latency.

Each bucket records calls begun, completed calls, interrupted calls and elapsed
milliseconds. A worker failure closes the currently active bucket as failed and
keeps the prefix. Its elapsed interval may include exception unwinding to the
worker catch. Later buckets remain zero. Replay buckets must form the original
executed prefix, and completed preparations must contain every replay bucket.
Aggregate sums must fit the same worker interval and corresponding available
original stage interval; the `1e-6` allowance addresses binary64 summation only.
It is not a timing or acceptance tolerance.

Clock faults, overlapping buckets, unknown names, unsafe counts and invalid
lifecycle operations set bounded collector fault flags. They make the
supplemental observation incomplete; they do not substitute a rendering value
or erase an original exception. A missing reply or unavailable trace stays
missing. Nothing manufactures a completed preparation or publication.

## Host retention, admission and failure priority

`observe_r0035_costs.py` composes the pinned original stage host in a fresh module
namespace. Exact reversible substitutions change only diagnostic labels, the
supplemental inspector and recorded adapter/collector identity. The original
driver, namespace check, local-only route guard, raw retention before validation,
trial cleanup and exception paths stay intact. The shared stage module is not
mutated.

Private evidence is retained in `r0035-chromium-timing-costs-observations` beside
the unchanged trial outputs. Final intake recomputes cost summaries from raw
traces. It also checks original reports, all three arms, actual preparation
process custody, exact source closure, the current namespace and all adapter,
base-host and collector identities. A fresh bounded final child performs the
namespace and full-source re-admission; no synthetic success receipt is used in
the operational path.

An original qualification failure stays `FAIL` even if supplemental costs are
`OBSERVED`. Only an originally passing trial population with complete
supplemental custody receives `OBSERVED_PREPARATION_COSTS`; it cannot receive a
generic `PASS`. `nativeQualification` remains
`UNCHANGED_ORIGINAL_REPORT_ONLY`, and human acceptance is outstanding. Missing or
invalid cost evidence cannot upgrade the original result. Route veto, isolation
failure, cleanup/retention failure and outer timeout retain their original
authority and stop behavior.

Optional preparation is bounded at 240 seconds; failure blocks this selected
lane without fallback. The unchanged original trial child has 480 seconds.
Final currentness has 90 seconds, and namespace closure has 75, giving a maximum
645-second lane boundary. The selected common preparation plus optional source
preparation plus lane total is 1,905 seconds, within the unchanged 2,640-second
coordinator and 45-minute workflow observation bounds. Combined long matrix or
R002F campaigns are not admitted by this selector.

## Source verification and limits

Registered source controls exercise actual original and transformed stellar and
replay functions, exact flux and patch bytes, nominal/index/population parity,
full replay output, worker ready/failure replies, and unchanged error behavior.
Both parity copies use the pinned original lab's `patch_refined` recipe for its
native-host publication hooks. The complete mathematical import population is
thus the original served lab source, including its unchanged display encoder.

host/coordinator controls cover full source closure, raw invalid-prefix retention,
strict completion types, changed preparation, namespace refusal, original
qualification failure, distinct labels and the actual planner path. A local
source preparation and plan admission are not native observations.

Independent exact-tree review is required before activation. Native screenshots,
timing evidence, physical qualification and human acceptance must come from
their own actual retained observations; this source packet supplies none of them.
